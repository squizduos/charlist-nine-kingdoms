# Планы

## Версия 0.2

1. Установить фиксированный размер для блоков в верхней части - 25-25-10-30-10 (в процентах)
2. Пофиксить тёмный и светлый шрифт при переименовании вкладок
3. Для заметок интегрировать простой Markdown-редактор
4. Скрывать по умолчанию неиспользуемые поля в развертываемый слайдер, который можно развернуть в любой момент.
5. Оптимизировать печатную версию - сейчас каждый блок выводится на отдельной странице. Секции 1 и 2 можно выводить на одной странице, как и секции 3 и 4, 5 и 6.
6. Внедрить поддержку истории изменений, фиксировать в отдельном блоке каждое изменение. Сделать рядом с кнопками отображение всей истории изменений.
   - Технически покрывается пунктом 7: у CRDT-документа (Automerge) история изменений встроена
     (каждое изменение адресуемо и обратимо), нужен только UI-список версий с восстановлением.
7. Синхронизация чар-листа между устройствами, с корректным слиянием одновременных правок
   и входом по ключу (без логинов/паролей). Архитектура:
   - CRDT на **Automerge** (`automerge-repo`), не FrigadeHQ/remote-storage - параллельные правки
     сливаются автоматически, история версий (см. пункт 6) - часть модели данных, а не надстройка.
   - "Ключ" = адрес документа в URL-фрагменте (`#doc=automerge:...`), как у Excalidraw/CryptPad -
     фрагмент после `#` браузер не отправляет на сервер, поэтому сервер не хранит пользователей,
     только маршрутизирует и складирует данные по этому адресу. Кнопка "Поделиться" рядом
     с "Загрузить/Сохранить" создаёт документ и копирует ссылку.
   - Сервер синхронизации (`automerge-repo-sync-server`) - второй контейнер рядом с nginx
     в существующем Docker/GHCR-пайплайне.
   - Этапы: 1) локальный переход store на Automerge-документ в IndexedDB вместо localStorage
     (без сети); 2) сеть между устройствами + кнопка "Поделиться"; 3) UI истории версий (пункт 6).
   - Компромиссы: +~300 КБ к бандлу (WASM-ядро); ссылка - единственный секрет (как пароль,
     без возможности отозвать доступ, только форк в новый документ); сервер синхронизации -
     новый постоянно работающий сервис (сейчас всё статическое).
