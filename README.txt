# Nine Kingdoms Character Sheets - Руководство по внутреннему устройству

## Обзор приложения

Это веб-приложение для управления персонажами ролевой игры "Nine Kingdoms" (Девять Королевств), 
построенное на Vue.js 3 с использованием Composition API и Pinia для управления состоянием.

## Архитектура приложения

## Детальное описание компонентов

### 2.1 Модель данных (Character.js)

Класс `Character` представляет структуру данных персонажа:

```javascript
class Character {
  constructor(data = {}) {
    this.id = data.id || this.generateId()
    this.name = data.name || `Персонаж ${this.id}`
    this.data = {
      // Основная информация
      characterName: 'Эмма',
      playerName: 'Семён',
      kitchenName: 'Лилиям',
      concept: 'Глупец',
      age: '21',
      gameType: 'Материк', // Новое поле вместо income
      characterId: '16825',
      
      // Характеристики (социальные, ментальные, физические)
      charisma: 0,
      manipulation: 0,
      // ... другие характеристики
      
      // Отслеживание повреждений
      stupidDamage: 0,
      lethalDamage: 0,
      mentalDamageBig: 0,
      mentalDamageSmall: 0,
      
      // Дополнительные параметры
      permanentWill: 0,
      rerolls: 0,
      experience: 0,
      
      // Части тела для отслеживания травм
      figureParts: {
        head: false,
        leftArm: false,
        rightArm: false,
        body: false,
        leftLeg: false,
        rightLeg: false
      }
    }
  }
}
```

**Ключевые методы:**
- `calculateDotLimits()` - Вычисляет лимиты для точек урона
- `getDisplayName()` - Возвращает отображаемое имя персонажа
- `toJSON()` / `fromJSON()` - Сериализация/десериализация

### 2.3 Компоненты

#### 2.3.1 App.vue - Главный компонент

#### 2.3.4 CharacterSheet.vue - Основной лист персонажа

## Система точек и лимитов

### 3.1 Логика заполнения точек

1. **Левый клик** - Заполняет точки от начала до выбранной
2. **Правый клик** - Очищает точки от выбранной до конца
3. **Блокировка** - Точки выше лимита блокируются и становятся серыми

### 3.2 Расчет лимитов

```javascript
calculateDotLimits() {
  const limits = {}
  
  // Урон зависит от храбрости + телосложения
  limits.lethalDamage = brawling + physique
  limits.stupidDamage = brawling + physique
  
  // Перебросы зависят от постоянной воли
  limits.rerolls = permanentWill
  
  return limits
}
```

### 3.3 Визуальное отображение

- **Пустые точки** - Серые (#ccc)
- **Заполненные точки** - Черные
- **Заблокированные точки** - Серые (#999) с opacity 0.6
- **Hover эффект** - Темно-серый (#666)

## Лучшие практики Vue.js

### 6.1 Composition API

- Использование `setup()` функции
- Реактивные ссылки (`ref`, `reactive`)
- Вычисляемые свойства (`computed`)
- Хуки жизненного цикла

### 6.2 Компонентная архитектура

- **Единая ответственность** - каждый компонент отвечает за одну функцию
- **Переиспользование** - DotLine компонент используется везде
- **Props/Events** - четкий интерфейс между компонентами
- **Слоты** - для гибкого контента

### 6.3 Управление состоянием

- **Pinia** для глобального состояния
- **Props** для передачи данных вниз
- **Events** для передачи данных вверх
- **LocalStorage** для персистентности

### 6.4 Производительность

- **Lazy loading** компонентов
- **Computed properties** для кэширования
- **v-show** вместо v-if где возможно
- **Key** для оптимизации списков

## Расширение функциональности

### 8.1 Добавление новых полей

1. Обновить модель `Character.js`
2. Добавить поля в компоненты
3. Обновить миграцию в `characterStore.js`

### 8.2 Добавление новых компонентов

1. Создать компонент в `src/components/`
2. Импортировать в родительский компонент
3. Добавить стили в `style.css`

### 8.3 Добавление новых типов точек

1. Расширить `DotLine.vue` компонент
2. Добавить логику в `calculateDotLimits()`
3. Обновить стили
