# Чар-лист Девяти Королевств

Веб-приложение для создания и управления чар-листами (листами персонажей) в сеттинге "Девять Королевств".

## Возможности

- Создание и редактирование чар-листов персонажей
- Поддержка двух типов персонажей: Материк и Фэйри
- Множественные вкладки для работы с несколькими персонажами одновременно
- Автоматическое сохранение в localStorage
- Экспорт и импорт персонажей в формате JSON
- Тёмная и светлая темы
- Печать чар-листов
- Адаптивный интерфейс

## Требования

- Node.js 18+ (рекомендуется 20+)
- npm 9+

## Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd charlist-nine-kingdoms

# Установка зависимостей
npm install
```


## Docker

### Сборка образа

```bash
docker build -t charlist-nine-kingdoms .
```

### Запуск контейнера

```bash
docker run -d -p 8080:80 --name charlist charlist-nine-kingdoms
```

Приложение будет доступно по адресу: http://localhost:8080

### Docker Compose (опционально)

Создайте файл `docker-compose.yml`:

```yaml
version: '3.8'

services:
  charlist:
    build: .
    ports:
      - "8080:80"
    restart: unless-stopped
```

Запуск:

```bash
docker-compose up -d
```

## Использование приложения

### Основные элементы интерфейса

1. **Заголовок** — название приложения "Девять королевств"
2. **Вкладки персонажей** — переключение между несколькими чар-листами
3. **Основная секция** — базовая информация о персонаже
4. **Секции характеристик** — атрибуты, рассудок, искусства и т.д.

### Управление персонажами

- **Новый персонаж** — создаёт новую вкладку с пустым чар-листом
- **Сохранить** — скачивает чар-лист в формате JSON
- **Загрузить** — открывает JSON-файл и создаёт новую вкладку с персонажем
- **Печать** — открывает диалог печати браузера

### Работа с вкладками

- Клик по вкладке — переключение на персонажа
- Двойной клик — переименование вкладки
- Кнопка "×" — закрытие вкладки
- Кнопка "+" — создание новой вкладки

### Типы персонажей

- **Материк** — стандартный тип персонажа с разделом "Сущность"
- **Фэйри** — персонаж с разделом "Королевства" вместо "Сущности"

### Сохранение данных

Все данные автоматически сохраняются в localStorage браузера. При закрытии и повторном открытии приложения все вкладки и персонажи будут восстановлены.

### Тема оформления

Кнопка с иконкой солнца/луны переключает между светлой и тёмной темами. Выбранная тема сохраняется в localStorage.
